## 📝 Descrição do Projeto

Este repositório contém o projeto final da disciplina de Programação II, que consiste em um sistema para o **Gerenciamento de uma Escola**.

O sistema foi desenvolvido para facilitar a administração de dados essenciais, provendo uma plataforma para o cadastro e controle das principais entidades de um ambiente educacional: **Turmas**, **Alunos** e **Professores**.

## ✨ Funcionalidades Principais

O sistema permite a gestão das seguintes entidades:

* **Turmas:** Cadastro e manutenção das turmas da escola.
* **Alunos:** Registro completo dos estudantes, incluindo sua alocação em turmas.
* **Professores:** Cadastro e informações dos docentes.

## 🛠️ Tecnologias Utilizadas

* **Linguagem de Programação:** Java
* **Sistema de Build:** Gradle

## 🚀 Como Executar o Projeto

Para rodar este projeto localmente, siga os passos abaixo:

### Pré-requisitos

Certifique-se de ter o **Java Development Kit (JDK) 8** ou superior instalado em sua máquina.

### Passos

1.  **Clone o repositório:**

    ```bash
    git clone [https://github.com/JB-2499/gerenciamento_escolar.git](https://github.com/JB-2499/gerenciamento_escolar.git)
    ```

2.  **Navegue até o diretório do projeto:**

    ```bash
    cd gerenciamento_escolar
    ```

3.  **Compile e execute o sistema usando o Gradle:**

    **Em sistemas Linux/macOS:**
    ```bash
    ./gradlew run
    ```

    **Em sistemas Windows:**
    ```bash
    .\gradlew.bat run
    ```

    O aplicativo deverá ser iniciado no console, apresentando o menu principal do sistema.
